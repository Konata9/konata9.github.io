MCP 探索笔记：5ire 一个聚合式 MCP 客户端

约 731 字大约 2 分钟

AIMCP工具

2025-04-05

引言

之前 AWS 的工程师来公司介绍 AWS Q Developer（以前的 Code Wisper）。其突破对话框，可以直接在命令行执行各种指令的能力着实让人心动。

后面和朋友聊天时，朋友推测应该是 MCP 集成的比较好。于是在想有没有不用打开 Windsurf 就能调用 MCP 的客户端？（其实 Claude 就是，只是当时并不知道）

5ire 一个聚合式的 MCP 客户端

不知道是大数据监听还是凑巧。第二天逛掘金时就看到了作者 Ironben 的文章《 看好 MCP，但用不了 Claude，所以做了一款 MCP 客户端 》。

进去一看，很惊喜。这款工具除了基本的 ChatBot 功能，还支持 MCP 的调用以及本地知识库。这不正是我在找的工具嘛！当即便推荐给朋友。

5ire 项目地址：https://github.com/nanbingxyz/5ire 目前已经 2.4K star，并且更新频率很高。

简洁的界面设计

5ire 的界面很简洁，所有功能都在左边的菜单栏并且每一项都很直白，并没有什么上手难度。

Workspace 菜单可以对模型进行配置。支持了 OpenAI、Claude、Google、DeepSeek 等主流模型。

OpenRouter 虽然不在列表中，但可以通过 Model Mapping 进行配置，只是 MCP 功能无法使用。

详细可以参考作者在 GitHub 上的回复[Bug] 模型映射无法使用工具tool https://openrouter.ai/api/v1/chat/completions not found, verify your API base. #126

Tools 菜单可以进行 MCP 的配置。作者提供了一个 MCP 市场，市场中的 MCP 可以一键安装。

安装完成后记得打开。

这样在后面对话中，就能调用到对应的 MCP 了。这里的 Web:fetch 便是在调用 Web MCP。

奇怪的是，如果使用 Web:fetch 反而拿不到回答，页面上确实没有具体价格。倒是只使用 Sequential Thinking 反而可以拿到期望的结果。

本地知识库由于我暂时并没有使用到，所以就不做介绍了。

总结

5ire 作为一个聚合式 MCP 客户端，提供了简洁直观的界面和强大的功能集成。它不仅支持多种主流 AI 模型，更重要的是实现了 MCP 工具的便捷调用。

MCP 市场的一键安装功能大大降低了使用门槛，而本地知识库的支持则为未来扩展提供了更多可能性。随着项目的持续更新（目前已达 2.4K star），相信它会成为 MCP 生态中的重要一环。
