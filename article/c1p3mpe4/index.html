MCP 探索笔记：查找与管理你需要的 MCP

约 928 字大约 3 分钟

AImcp工具

2025-04-04

引言

在 Windsurf 的一次更新后，发现多了个 MCP 服务选项。外加多次在猫鱼周刊上看到相关文章，便开始了解和关注 MCP。

MCP（Model Control Protocol） 能做什么

我自己理解大模型和 MCP 类似 VSCode + 各种插件。MCP 可以让大模型通过通用协议调取不同资源。

利用 MCP 的能力可以让大模型跳出对话框，直接对系统进行操作。人就可以免去复制黏贴的步骤，直接下指令。

黄叔有一篇非常易懂的实践文章 10分钟搞定高德地图MCP！我用AI解决了约会地点选择难题 ，看完就能明白 MCP 在其中的作用。

哪里可以找到 MCP 服务

只要遵循接口定义，任何人都能开发 MCP 服务。

那是否有类似 npm 的仓库，可以方便地找到 MCP 服务呢？答案是肯定的。

1. mcp.so

mcp.so 是一个汇总了 MCP 服务的网站。包含了一些官方 MCP Server，如Fetch、Sequential Thinking、Google Map 等、也有第三方如高德地图等 MCP 服务。

每个 MCP 的页面也都提供了简介和安装方式，比较友好。

2. Awesome MCP Servers

awesome-mcp-servers 是一个 Awesome 项目，列出了许多 MCP 服务。按照功能、项目语言进行分类。

配置 MCP - JSON 与 Toolbase

像 Windsurf 这样的编辑器会自带一些 MCP 服务。通过 cmd + shift+ p 输入 MCP 找到 'Windsurf:MCP Configuration Panel'，点击即可添加。

对于非自带的 MCP 服务，我们就需要手动进行配置。配置文件通常以 JSON 格式存在，配置的方式通常会在对应 MCP 服务的发布页中说明。一般在对应的 GitHub 页面上就能找到。

点击右上角的 'Add custom server' 就会打开配置文件，填上对应的配置即可。

{
	"mcpServers": {
		"sequential-thinking": {
			"command": "npx",
			"args": [
				"-y",
				"@modelcontextprotocol/server-sequential-thinking"
			]
		},
		"fetch": {
			"command": "uvx",
			"args": [
				"mcp-server-fetch"
			]
		}
	}
}

配置完成后，就能在 Cascade 面板中看到对应的服务。绿色说明服务已配置成功，黄色或者红色可能是 Windsurf 没能成功连上 MCP。重启 IDE 或者刷新或许可以解决。

当然如果觉得单独配置 JSON 比较麻烦的话，还有一个管理 MCP 服务的工具 toolbase。

这个工具提供了 GUI 界面，我们可以开启或关闭上面的 MCP 功能。像 Windsurf、Cursor 这样的 AI 客户端，只要对接 Toolbase 这一个 MCP 就足够了。

总结

MCP 服务为 AI 编辑器带来了突破性的能力扩展，让大模型能够跳出对话框直接操作系统。本文介绍了几种查找和管理 MCP 服务的方法：

  • 查找 MCP 服务：

    • mcp.so：官方和第三方 MCP 服务的集中展示平台
    • awesome-mcp-servers：按功能和语言分类的 MCP 服务汇总

  • 管理 MCP 服务：

    • Windsurf 内置面板：适合快速添加官方支持的 MCP 服务
    • JSON 配置文件：适合需要自定义和精细控制的场景
    • toolbase 工具：提供 GUI 界面，一站式管理多个 MCP 服务

合理配置和管理 MCP 服务不仅能提升开发效率，更能让 AI 辅助编程的体验更加流畅自然，让我们真正体验到"指挥"AI 工作的乐趣。
